# Validation controls

This public directory contains the versioned validation plan, locked tuning/held-out assignment,
dataset registry, and source-overlap map needed to review the evaluation checks.

It intentionally does not contain raw source files, per-sample tables, generated QC directories,
tuning metrics, held-out metrics, plots, or validation conclusions. Those files remain outside
the public release unless they pass a separate source-rights and disclosure review.

Current status: validation is in progress; registry admission and full protocol/code freeze remain
gated, and no held-out result is claimed.
